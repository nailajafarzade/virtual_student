# Virtual Student

Virtual Student is an AI-powered virtual learning platform designed to support personalized learning through interactive tutoring and student progress tracking.

## Project Structure

- `vstudent-frontend/` — React and TypeScript frontend
- `backend/` — Java Spring Boot backend
- `ai-service/` — Python FastAPI service for AI-related functionality

## Technologies

- **Frontend:** React, TypeScript, Vite
- **Backend:** Java, Spring Boot
- **AI Service:** Python, FastAPI
- **Database:** PostgreSQL
- **AI Integration:** Large Language Models (LLMs)

## Project Status

Currently under active development.

## Purpose

The project aims to provide an interactive virtual learning experience with AI-assisted tutoring and student progress management.
